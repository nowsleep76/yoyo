# 물때 탭 데이터 정확도 문제 진단

## 🔍 문제 원인 분석

### 1. 실시간 여부: **혼합 상태**
- **정확한 데이터**: 음력 날짜, 물때, 만조/간조 시각 ✅
- **시뮬레이션 데이터**: 시간별 수위, 조류 세기, 바람, 날씨 ❌

### 2. 상세 원인

**코드 위치**: `services/kma_weather_service.py` (line 126-132)

```python
# 기상청 예보는 보통 D+2, 3일까지만 제공
if target < today or (target - today).days > 3:
    return None  # ← 과거 날짜는 데이터 조회 안 함!
```

**문제점**:
- 과거 날짜(어제, 그제 등) 선택 시 → **None 반환** → API 데이터 없음
- 미래 D+3일 이상 선택 시 → 역시 API 데이터 없음
- **결과**: 과거/미래 극단 날짜는 모두 **시뮬레이션 곡선** 사용

**시뮬레이션 데이터의 문제**:
- 수위: sin 곡선으로 계산 (실제 일출/일몰 시간 반영 안 함)
- 조류: 수위 변화 미분으로 근사치 계산
- 바람/날씨: 고정 패턴으로 생성 (실제 날씨 반영 안 함)
- 강수확률: 고정 룰로만 계산

## ✅ 해결 방법

### Option 1: 기상청 기후 데이터 API 추가 (권장)
**장점**: 한국 공식 데이터, 과거 실측값 포함
**단점**: API 신청 필요, 약 1-2일 승인 소요

```
1. https://data.go.kr 에서 "기상청_과거날씨데이터" 신청
2. API: https://data.go.kr/datafile/2023-11-27/.../areaBasedDailyData
3. 과거 평균값 기반 선택 가능
```

### Option 2: KHOA 해양관측 API 확충 (실시간)
**장점**: 실제 해양 관측값 (수온, 파고, 조류)
**단점**: 제한된 관측점만 지원, 예보 미제공

```
현재 상태: 미통합
추가 필요: hourly 수온, 조류 강도 조회
```

### Option 3: 하이브리드 접근법 (최적)
```
오늘/내일/모레 (D+0 ~ D+2)
  ↓
KMA 실시간 예보 API 사용
  ↓
과거 3일 이상 / 미래 4일 이상
  ↓
KHOA 관측값 또는 통계값 사용
```
