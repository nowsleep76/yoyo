# 📊 한국 주식 분석 대시보드

거래량 기준 상승률이 높은 한국 주식을 실시간으로 분석하고 시각화하는 웹 대시보드입니다.

## 🎯 기능

- 📈 **실시간 주식 분석**: 한국 시가총액 상위 20개 종목 분석
- 📊 **시각화**: Plotly를 이용한 인터랙티브 차트
- 🎨 **반응형 디자인**: Streamlit으로 만든 사용하기 쉬운 인터페이스
- 🔄 **실시간 업데이트**: 언제든 데이터 새로고침 가능
- 📋 **상세 데이터**: TOP 20 회사의 상세 정보 표시

## 📊 분석 지표

### 거래량 기준 상승률 (Weighted Score)
```
스코어 = 주가 상승률(%) × (거래량 / 1,000,000)
```
- 거래량이 높으면서 상승률도 높은 종목을 우선순위로 표시
- 시장에서 주목받는 주식을 빠르게 파악 가능

### 표시 항목
- 💰 **현재가**: 현재 주가
- 📈 **상승률**: 어제 대비 상승/하락률 (%)
- 📊 **거래량**: 현재 거래량
- 🔄 **거래량 변화**: 어제 대비 거래량 변화율 (%)
- ⭐ **점수**: 거래량 가중 상승률

## 🚀 설치 및 실행

### 필수 조건
- Python 3.8 이상
- pip

### 설치

```bash
# 저장소 클론
git clone https://github.com/nowsleep76/yoyo.git
cd yoyo

# 의존성 설치
pip install -r requirements.txt
```

### 실행

```bash
# Streamlit 앱 실행
streamlit run app.py
```

앱이 자동으로 브라우저에서 실행됩니다 (기본: http://localhost:8501)

## 📦 의존성

- **streamlit**: 웹 대시보드 프레임워크
- **yfinance**: Yahoo Finance에서 주식 데이터 수집
- **pandas**: 데이터 분석 및 처리
- **plotly**: 인터랙티브 시각화

## 🎛️ 사용 방법

1. **데이터 새로고침**: 사이드바의 "🔄 데이터 새로고침" 버튼으로 최신 데이터 수집
2. **분석 기간 변경**: 사이드바에서 1~30일 범위 선택
3. **차트 상호작용**: 마우스로 차트의 영역을 확대/축소하거나 항목 선택
4. **데이터 테이블**: 스크롤 가능한 상세 데이터 확인
