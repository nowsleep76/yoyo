# 한국 주식 차트 뷰어 📈

개별 한국 종목의 상세 차트를 분석할 수 있는 Streamlit 웹 앱입니다.

## 기능

- ✅ 20개 주요 종목 선택 (삼성전자, SK하이닉스, NAVER, Kakao 등)
- ✅ 캔들스틱 차트 (OHLC)
- ✅ 거래량 차트
- ✅ 주요 통계 (현재가, 고가, 저가, 평균 거래량)
- ✅ 상세 데이터 테이블
- ✅ 기간별 분석 (7일~365일)

## 설치 및 실행

### 1. 필요한 패키지 설치

```bash
pip install -r requirements.txt
```

### 2. 앱 실행

```bash
streamlit run app.py
```

앱은 자동으로 브라우저에서 열리며 `http://localhost:8501`에서 접속할 수 있습니다.

## 사용 방법

1. **좌측 사이드바**에서 원하는 주식 종목을 선택
2. **분석 기간** 슬라이더로 조회 기간 설정 (기본값: 90일)
3. **캔들스틱 차트**에서 가격 변동 추이 확인
4. **거래량 차트**에서 거래량 변화 확인
5. **상세 데이터** 테이블에서 일별 정보 조회
